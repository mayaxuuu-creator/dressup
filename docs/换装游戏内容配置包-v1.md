## 四、锚点与美术规范（画第一件衣服前定死）

1. **统一画布**：所有单品同一规格导出——1000×1500 透明 PNG（2 倍图，实际显示 500×750），角色固定全身正面站姿。
2. **素体参考图先行**：先画一张“底妆角色 + 各槽位参考框标示”的素体图（发型框、躯干框、裙框、鞋框、配饰框），作为**唯一对齐标准**，所有单品对着它作画。这张图没定稿前不动笔画任何服饰。
3. **命名规范**：`槽位_编号_名称.png`，如 `dress_d03_moonpurple.png`。
4. **交付即试穿**：每件单品交付时，必须在素体参考图上贴一张试穿对齐截图，目视无错位才算过。
5. 程序侧只做“原坐标贴图”，不做缩放位移换算——对齐责任全在美术侧的画布纪律上。

## 五、S 级自检（内容保障要求的验证）

> 机制 v2 要求：每章解锁后至少能组出两套“件件符合”的满分造型。以下配方全部按 v2 公式手算通过。

**开局首穿**（F01+T01+B01+S01，配饰空，上下装方案 5 件）：
契合 48 + 配色 12 + 完整 16 = **76 · A**，过第一章线（60），但拿不到 S——正好逼玩家去衣柜里动手。

| 章节 | 满分配方一（连衣裙方案） | 满分配方二 |
|---|---|---|
| 第一章（仅初始衣柜） | F02+D01+S01+A01 = **100 S** | F03+T01+B01+S02+A02 = **100 S** |
| 第二章（含舞会系列） | F05+D03+S03+A03 = **100 S** | F04+D04+S03+A03 = **100 S** |
| 第三章（含复古系列） | F06+D05+S04+A04 = **100 S** | F06+T03+B03+S04+A04 = **100 S**（另有 F03 替换 F06 的第三套变体） |

三章全部满足“至少两套”要求 ✓；首穿不满分、动手指日可待 ✓；单件偏色容忍（95 S）留给个性化空间 ✓。
