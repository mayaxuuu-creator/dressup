# 千禧衣橱 🎀 经典换装

复刻 4399/7K7K 经典 Flash 换装体验的千禧甜美风纸娃娃小游戏：自由换装 + 3 章主题挑战评分。

- 单 HTML 零依赖，角色与 25 件服饰全部为内嵌 SVG 矢量（对齐零风险）
- 评分公式与内容配置严格对齐 `docs/` 下两份设计文档
- 本地存档（localStorage）、造型照导出 PNG、WebAudio 合成音效、移动端适配

## 玩法
- **自由换装**：衣柜随意搭、随机一键出装、换背景、隐藏 UI、拍照存图
- **主题挑战**：三章情境（开学心动日 → 月光天台舞会 → 复古唱片派对），按风格标签 + 推荐色系评分，过关解锁新服饰，通关第三章获称号「千禧搭配大师」+ 纪念背景

## 运行
浏览器直接打开 `index.html` 即可。
